# ICANSII SideStore

Ce dépôt contient les applications ICANSII distribuées via **SideStore** et publiées dans les **Releases**.

## À propos

Ce repository sert de point de distribution pour les versions signées des applications ICANSII destinées à être installées avec SideStore.

Les fichiers `.ipa` et les notes de version sont disponibles dans l’onglet **Releases**.

## Installation avec SideStore

SideStore doit déjà être installé sur l’iPhone.

<p align="center">
  <a href="sidestore://source?url=https://icansii.github.io/icansii-sidestore/apps.json">
    <img
      src="https://img.shields.io/badge/Ajouter%20la%20source%20à%20SideStore-6C5CE7?style=for-the-badge&logo=apple&logoColor=white"
      alt="Ajouter la source ICANSII à SideStore"
    />
  </a>
</p>

Une fois la source ajoutée, ouvrez SideStore puis sélectionnez **ICANSII 5** ou **ICANSII 6**.


## Installation avec iloader

1. Ouvrir l’onglet **Releases** du dépôt.
2. Télécharger la dernière version de l’application souhaitée.
3. Installer l’IPA via [iloader](https://iloader.site/)

## Contenu des releases

- Fichiers `.ipa`

- Corrections de bugs
- Nouvelles fonctionnalités
