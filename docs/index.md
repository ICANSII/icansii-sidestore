# Installer ICANSII avec SideStore

Installez **ICANSII 5** ou **ICANSII 6** sur un iPhone, puis maintenez
l’application active grâce à SideStore.

<div class="icansii-actions">
  <a class="md-button md-button--primary" href="get-started/">Commencer l’installation</a>
  <a class="md-button" href="https://icansii.github.io/icansii-sidestore/add-source.html">J’ai déjà SideStore</a>
</div>

</div>

<div class="icansii-grid" markdown>

<div class="icansii-card" markdown>
### 1. Installer SideStore

Préparez l’iPhone, LocalDevVPN et iloader, puis réalisez l’installation initiale.

[Voir le guide](get-started/install-sidestore.md)
</div>

<div class="icansii-card" markdown>
### 2. Ajouter ICANSII

Ajoutez la source officielle ICANSII à SideStore en un seul geste.

[Ajouter la source](get-started/add-source.md)
</div>

<div class="icansii-card" markdown>
### 3. Installer l’application

Choisissez ICANSII 5 ou ICANSII 6 dans le catalogue.

[Installer ICANSII](get-started/install-icansii.md)
</div>

<div class="icansii-card" markdown>
### 4. Actualiser chaque semaine

Gardez SideStore et les applications actives avant la fin des sept jours.

[Comprendre l’actualisation](get-started/refresh.md)
</div>

</div>

!!! info "Déjà équipé de SideStore ?"
    Ouvrez directement la page **Ajouter la source ICANSII**. Le lien HTTPS
    intermédiaire est nécessaire parce que GitHub filtre les liens
    `sidestore://` dans les README.
