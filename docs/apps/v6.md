# ICANSII 6

ICANSII 6 est une version expérimentale qui intègre notamment :

- la visualisation et le paramétrage du terrain ;
- la transmission haptique ;
- le test manuel de la ceinture ;
- la prévisualisation du modèle de détection.

[Installer depuis SideStore](https://icansii.github.io/icansii-sidestore/add-source.html){ .md-button .md-button--primary }
