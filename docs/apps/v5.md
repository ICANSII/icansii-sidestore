# ICANSII 5

ICANSII 5 est une application d’assistance destinée aux personnes malvoyantes.
Elle regroupe notamment :

- la visualisation du terrain ;
- la sélection du modèle de détection ;
- la connexion avec la ceinture haptique.

[Installer depuis SideStore](https://icansii.github.io/icansii-sidestore/add-source.html){ .md-button .md-button--primary }
