# Ajouter la source ICANSII

## Ajout en un geste

Ouvrez cette page depuis Safari sur l’iPhone où SideStore est installé :

[Ajouter ICANSII à SideStore](https://icansii.github.io/icansii-sidestore/add-source.html){ .md-button .md-button--primary }

La page HTTPS ouvre ensuite le lien :

```text
sidestore://source?url=https://icansii.github.io/icansii-sidestore/apps.json
```

## Ajout manuel

Dans SideStore :

1. ouvrez **Sources** ;
2. touchez **+** ;
3. saisissez l’URL suivante :

```text
https://icansii.github.io/icansii-sidestore/apps.json
```

La source **ICANSII** doit alors apparaître avec ICANSII 5 et ICANSII 6.
