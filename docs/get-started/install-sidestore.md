# Installer SideStore

Cette page fournit un parcours en français fondé sur la documentation officielle
actuelle de SideStore.

## Prérequis

Préparez :

- un iPhone ou un iPad protégé par un code ;
- un ordinateur Windows, macOS ou Linux pour l’installation initiale ;
- un compte Apple ;
- une connexion Wi-Fi ;
- **LocalDevVPN** sur l’appareil ;
- **iloader** sur l’ordinateur.

<a class="md-button" href="https://docs.sidestore.io/docs/installation/prerequisites" target="_blank">
Consulter les prérequis officiels
</a>

## Installation avec iloader

1. Connectez l’iPhone à l’ordinateur par USB.
2. Acceptez **Faire confiance à cet ordinateur** sur l’iPhone.
3. Ouvrez iloader.
4. Connectez le compte Apple.
5. Sélectionnez l’iPhone.
6. Choisissez **Install SideStore (Stable)**.
7. Sur l’iPhone, faites confiance au profil développeur dans :
   **Réglages → Général → VPN et gestion de l’appareil**.
8. Activez le **mode développeur** si iOS le demande.
9. Ouvrez LocalDevVPN et touchez **Connect**.
10. Ouvrez SideStore et connectez le même compte Apple.
11. Dans **My Apps**, touchez le compteur **7 DAYS** à côté de SideStore pour
    effectuer la première actualisation.

<a class="md-button" href="https://docs.sidestore.io/docs/installation/install" target="_blank">
Ouvrir la procédure officielle actuelle
</a>

!!! warning "Ne pas oublier LocalDevVPN"
    LocalDevVPN doit être connecté pour installer, mettre à jour ou actualiser
    une application dans SideStore.
