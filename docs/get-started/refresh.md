# Actualiser les applications

Les applications installées avec un compte Apple gratuit doivent être
régulièrement resignées.

## Actualisation manuelle recommandée

Avant que le compteur n’atteigne zéro :

1. connectez l’iPhone au Wi-Fi ;
2. ouvrez LocalDevVPN et touchez **Connect** ;
3. ouvrez SideStore ;
4. ouvrez **My Apps** ;
5. touchez **Refresh All** ou le compteur de chaque application.

## Avant une démonstration

Effectuez une actualisation manuelle un ou deux jours avant la démonstration.
Ne comptez pas uniquement sur l’exécution en arrière-plan d’iOS.

!!! danger
    Une application arrivée à expiration ne se lance plus. SideStore lui-même
    doit donc être actualisé en priorité.
