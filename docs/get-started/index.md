# Démarrer

L’installation se déroule en quatre étapes.

<div class="icansii-steps" markdown>

1. **Installer SideStore** une fois depuis un ordinateur.
2. **Ajouter la source ICANSII** dans SideStore.
3. **Installer ICANSII 5 ou ICANSII 6**.
4. **Actualiser les applications** avant la fin de leur période de sept jours.

</div>

[Commencer par l’installation de SideStore](install-sidestore.md){ .md-button .md-button--primary }

!!! tip
    SideStore n’a besoin de l’ordinateur que pour son installation initiale.
    Pour installer, mettre à jour ou actualiser une application ensuite,
    l’iPhone doit être en Wi-Fi et **LocalDevVPN doit être connecté**.
